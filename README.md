# Auspex v.11

Aide de jeu Warhammer 40 000 (11e édition) : logigrammes de tour, d'attaque, de tactique et de stratégie, plus un « Mode Hunter » qui estime quelle unité de ton armée doit chasser quelle unité adverse.

Outil de fan non officiel, non affilié à Games Workshop. Les données de factions (Tyranids, Adeptus Mechanicus, Space Marines) proviennent d'une extraction automatique de Wahapedia : à vérifier avant de s'y fier.

Hébergé avec GitHub Pages. Pour tester en local : `python -m http.server` puis http://localhost:8000
